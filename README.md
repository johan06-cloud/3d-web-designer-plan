# 3D Web Designer Plugin

A design-focused Antigravity plugin for creating 3D website designs and previews.

## What It Does

This plugin turns the agent into a 3D web design expert that can generate:

- **🎨 Design concept images** — AI-generated mockups of 3D website designs (like Figma concepts)
- **🖥️ Interactive CSS 3D previews** — Live interactive widgets in chat with hover effects, glassmorphism, perspective transforms
- **🌐 Three.js HTML previews** — Standalone HTML files with full 3D scenes, models, and orbit controls you open in your browser

## Skills Included

| Skill | What It Does |
|:---|:---|
| `design-concept` | Generates AI image mockups of 3D website designs |
| `interactive-preview` | Creates CSS 3D interactive previews inline in chat |
| `3d-scene-preview` | Creates standalone Three.js HTML files with 3D scenes |
| `3d-design-system` | Provides design guidance on colors, lighting, depth, motion |

## Example Prompts

- "Design a dark tech landing page with floating 3D shapes and glassmorphism"
- "Show me an interactive card grid with 3D hover effects"
- "Create a Three.js scene with a rotating geometric shape on a gradient background"
- "What color palette works best for a 3D portfolio site?"
- "Design a product showcase page for headphones with 3D depth effects"

## Resources

The plugin includes curated references for:
- **CSS 3D patterns**: Card tilt, glassmorphism, parallax, card flip, carousel, and more
- **Free 3D models**: Poly Haven, Sketchfab, pmndrs Market, Kenney Assets
- **Free HDRIs**: Poly Haven (CC0 environment maps for reflections)
- **Free textures**: Poly Haven, ambientCG (PBR texture sets)
- **Design principles**: Depth perception, lighting psychology, motion design, typography
