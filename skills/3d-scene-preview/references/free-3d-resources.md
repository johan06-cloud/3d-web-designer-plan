# Free 3D Resources

Curated collection of free, high-quality resources for 3D web design.
All resources listed here are free for commercial use unless noted.

---

## 3D Models

### Poly Haven (polyhaven.com/models)
- **License**: CC0 (completely free, no attribution required)
- **Quality**: Very high, production-ready
- **Formats**: .glb, .gltf, .fbx, .blend
- **Best for**: Architectural, furniture, nature, props
- **Direct download**: `https://dl.polyhaven.org/file/ph-assets/Models/`

### Sketchfab (sketchfab.com)
- **License**: Varies (filter by "Downloadable" + CC license)
- **Quality**: Varies from amateur to professional
- **Formats**: .glb, .gltf, .fbx, .obj
- **Best for**: Characters, vehicles, sci-fi, stylized
- **API**: Available for programmatic search/download

### pmndrs Market (market.pmnd.rs)
- **License**: CC0, free for any use
- **Quality**: Curated, optimized for web
- **Formats**: .glb (web-optimized)
- **Best for**: React Three Fiber projects, already optimized for web
- **Note**: Models are pre-optimized with Draco compression

### Kenney Assets (kenney.nl)
- **License**: CC0, public domain
- **Quality**: Stylized/low-poly, game-ready
- **Formats**: .glb, .fbx, .obj
- **Best for**: Game-like designs, low-poly aesthetics, UI assets

### Three.js Examples Models
- **URL**: `https://threejs.org/examples/`
- **License**: MIT
- **Models available**: Stanford Bunny, Utah Teapot, Suzanne, etc.
- **Best for**: Testing and prototyping

## HDR Environment Maps (HDRIs)

### Poly Haven HDRIs (polyhaven.com/hdris)
- **License**: CC0
- **Resolutions**: 1K, 2K, 4K, 8K, 16K
- **Best for**: Realistic reflections and lighting
- **Popular picks for web**:
  - `studio_small_09` — Clean studio lighting
  - `venice_sunset` — Warm outdoor
  - `moonless_golf` — Dark dramatic
  - `industrial_workshop` — Neutral indoor
- **Direct URL pattern**:
  `https://dl.polyhaven.org/file/ph-assets/HDRIs/hdr/1k/<name>_1k.hdr`
- **Tip**: Use 1K for web (smaller file, still good reflections)

### ambientCG (ambientcg.com)
- **License**: CC0
- **Formats**: HDR, EXR
- **Best for**: Supplementary environment maps

## Textures & Materials

### Poly Haven Textures (polyhaven.com/textures)
- **License**: CC0
- **Types**: PBR texture sets (diffuse, normal, roughness, etc.)
- **Best for**: Realistic materials on 3D objects

### ambientCG (ambientcg.com)
- **License**: CC0
- **Types**: PBR materials, decals, HDRIs
- **Best for**: Large variety of materials

### Poliigon (poliigon.com) — Free tier
- **License**: Royalty-free (account required)
- **Types**: Premium PBR textures
- **Best for**: Photorealistic materials

## Fonts for 3D Web Design

### Google Fonts (fonts.google.com)
- **Recommended for 3D sites**:
  - **Inter** — Clean, versatile sans-serif
  - **Space Grotesk** — Geometric, techy feel
  - **Plus Jakarta Sans** — Bold, modern
  - **JetBrains Mono** — Monospace for tech/code aesthetics
  - **Playfair Display** — Elegant serif for luxury
